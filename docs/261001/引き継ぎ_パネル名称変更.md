## 4. 推奨する作業順

0. **準備**: 置換対応表（大小文字別 `Overview/overview/OVERVIEW` 等）を確定。`WorkoutSetting`→`DevelopSetting` の扱いを決める。専用ブランチ、`npm test` / `npm run build:server` が通る状態から開始。
1. **永続データの互換層を先に入れる（①②③）**: 読込を新旧両対応にし（`managedChat.ts` の正規表現に新旧名を許容、設定キーは旧→新に読み替え）、書込みは新名のみ。内部名はまだ変えない。
2. **型と定数の改名（④）**: `PanelThemeKind`、`PANELS`、`panelId`、FocusName系。`tsc` で漏れを洗い出す。
3. **クラス名・プロパティ名・状態キー（③⑤のTS部分）**: 1パネルずつ（Overview→Workout→ReThink）。`git mv` で履歴を保つ。パネルごとに `tsc`・テスト・コミット。
4. **コンポーネントディレクトリ・ファイル・CSS（⑤）**: `.tsx`/`.css` を同名セットで維持（CLAUDE.md規約）。`body[data-focus-column]` の値はTS側と同一コミットで揃える。
5. **表示文字列とドキュメント（⑥）**: タブ名、README、docs、`DefaultColor.md`、`DefaultShortcut.md`、CLAUDE.md。`docs/ThinkSupport/*`（過去の実装記録）は旧名のまま残すか注記にするかを決める。
6. **互換層の撤去（任意・後日）**: 旧データ移行後に外す。

## 5. 実施済み（コミット `da5e254`）

WorkoutSetting パネル（旧「Workout設定」）の整理。

- `MediaType` / `WorkoutViewMode` / `SettingsType` の `'workout'` を **`'panes'`** に変更。`WorkoutViewMode` の既定値も `'panes'`。
- タブ名「Workout設定」→「**Pane設定**」、タブ `id` を `'Workout'` → `'Panes'`。フォーカス名は `WorkoutSetting.Workout` → `WorkoutSetting.Panes`（`src/utils/getFocusName.ts`）。

- `WorkoutSettingPanel.Mode.Name`（`TTUIStateManager.ts`）の既定値・候補を `Panes` に変更。**保存済みの旧値 `Workout` は setter で `panes` に読み替える**。
- 縦メニューの順序を「Pane設定」「会話履歴」「区切り線」「TextEditor設定」「Markdown設定」「DataGrid設定」「Card設定」「Graph設定」「Html設定」に変更（`src/components/WorkoutPanel/WorkoutTabBar.tsx`）。Editモードでは会話履歴が非表示になるため区切り線は「Pane設定」の直後。

## 6. 未決事項・残課題

1. **旧データの扱い**: 互換読込を当面残すか、Vaultの旧データを一括変換するか。BigQuery上の分は書き換えの影響が大きいので互換読込を残す方が安全と考えている。
2. **`MediaType` の `'panes'` の整理**: 現状 `MediaType` は「ペインの表示形式」と「設定パネルのタブ」を兼ねている（`SettingsType = Extract<MediaType, …>`）。ペインの `MediaType` に `'panes'` が入る実質的な意味はなく、描画は `TextEditorMedia` へのフォールバックのみ（`WorkoutArea.tsx`）。→ `MediaType` から `'panes'` を外し、設定タブ専用の型に切り離すのが筋。ペインに保存された旧値 `'workout'` が存在する場合の読替え処理は未対応（保存経路は未確認）。
3. **`PanelThemeKind` の `'Workout'`**（`src/utils/panelTheme.ts`）: これはペインとは無関係で、テーマ色設定の対象種別。`CSS_PREFIX` で `--workout-base` / `--workout-content-bg` というCSS変数の接頭辞になり、ステータスID `Workout.Theme`（`docs/DefaultColor.md`）にもなる。改名時は CSS変数の一括置換が必要で、**`Workout.Theme` はユーザー保存済み色設定のキーなので手順1の互換対象**。保存済み設定ファイルに実在するかは未確認。
4. **ショートカットのモード循環順**（`src/views/TTFocusedPanelActions.ts` の `PANEL_VIEW_MODES.WorkoutSetting`）: 現状 `panes → texteditor … graph → chat` で、メニューの見た目（`panes → chat → texteditor …`）と異なる。揃えるか未回答。
5. **ユーザー保存済み設定のうち `WorkoutSetting.Workout` スコープを使うもの**: リポジトリ内には該当なし。ユーザー側にあれば `WorkoutSetting.Panes` に直す必要がある。
6. **`TaskSeed` を将来 Seeds パネルの概念に合わせて改名するか**、別概念として残すか。
7. **`docs/ThinkSupport/*` の過去記録を書き換えるか**（手順5で決める）。
8. **パネルID `'workout'`**（`PanelArea.tsx` / `VerticalTabBar.tsx` / `panelTheme.ts`）は今回触っていない。パネル名の改名時（Develop化）に一緒に扱う。
