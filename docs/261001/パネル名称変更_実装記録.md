# パネル名称変更の実装記録

## 名称

| 旧名 | 現在の名前 |
|---|---|
| Overview / OverviewPanel | Seeds / SeedsPanel |
| Workout / WorkoutPanel | Develop / DevelopPanel |
| WorkoutSetting / WorkoutSettingPanel | DevelopSetting / DevelopSettingPanel |
| ReThink / ReThinkPanel | Harvest / HarvestPanel |

画面の「Pane設定」はそのまま使う。`TaskSeed` と単数形の `seed` は課題の初期値を表す別概念として維持する。`MediaType` からの `panes` の分離はこの改名に含めない。

## 旧データの読込

- 既存Chatタイトルの旧担当名を読み取り、現在のパネル一覧とChatを開く操作では新名として扱う。既存Chat本文・タイトルは読込時に書き換えない。新しいChatは新名で作る。
- `taskRelation.panel: 'Workout'` を読み、新しいサブ課題は `'Develop'` で保存する。
- UI状態・色設定の旧Status ID、フォーカス名、ステータスバーの表示対象を読込時に新名へ正規化する。新たにシリアライズするUI状態は新名を使う。
- 保存済みショートカットの旧フォーカス名と旧アクション名を読込時に新名へ正規化する。`docs/DefaultShortcut.md` は新名を使う。
- パネル別Chat選択とSeedsの検索履歴は旧localStorageキーから復元し、新キーへ保存する。

BigQueryの既存レコードを一括更新しない。`docs/ThinkSupport` と過去のREADME更新履歴は、当時の名称を示す記録として残す。

## 確認

- 改名前の型検査と533テストが成功。
- 改名後の型検査、旧データ互換テストを含む全テスト、本番フロントエンドビルドが成功。
- Vite画面でSeedsの表示名・色・フォーカス表示を確認。バックエンドを起動していないため、実Vaultの読込を伴う画面操作は未確認。
- 全体Lintには既存の `src/views/TTPanelAreaWidth.test.ts` と `tmp` 内のスクリプトのエラーがある。名称変更部分については型検査・テスト・ビルドで確認した。
