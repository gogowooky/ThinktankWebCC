# AIインタビュー優先UI

## 方針

ユーザーは課題管理用の項目を順番に埋めるのではなく、AIChatで普段の言葉を使って相談する。AIは既に話された内容から目的、制約、完了条件などを読み取り、課題を進めるために重要な不明点だけを一度に一問確認する。同じ内容を聞き直さず、読み取った内容は候補として短く確認する。

AIの候補だけで本人の決定や課題完了を確定しない。保存を伴う最終的な採用は本人の操作で行う。

## 今回の変更

Overview>分析の先頭に「AIと整理する」を置き、関連するChatのAIChatを開けるようにした。従来前面に並んでいた課題概要の手入力、厳密な到達状態、Agent、外部連携、File Search設定は「詳細な記録・進捗・連携」へ折りたたんだ。

分析画面に直接置かれていたBundle単位の会話欄は、選択Chatへ会話を保存するという合意と重複するため外した。AIとの会話は各パネルの上部リストでChatを選んだAIChatに集約する。

AIChatは「送信」ボタンそのものを送信確認として扱い、メッセージごとの確認チェックを廃止した。参照範囲や接続状態などは引き続き「参照情報・その他」で確認できる。

サーバーの会話方針には、一括質問を避けること、過去の発言から読み取ること、不明点を一問に絞ることを追加した。

## 次の段階

AIが提示した目的・完了条件などの候補を、ユーザーが会話で修正して「これでよい」と確認した後、Bundleの課題概要へ一括採用する処理を追加する。手入力欄は採用後の細かな修正手段として残す。
