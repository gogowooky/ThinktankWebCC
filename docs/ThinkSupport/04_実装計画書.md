## 1. 対象範囲と到達点

Bundleを正本とするAI-neutralな基盤の上に、共通コンテキスト、課題を俯瞰するOverview、資料に基づく対話、Agent処理、外部同期を段階的に追加する。

最初の利用可能な到達点は「AIなしで資料と進行情報を手動管理できる新Overview」。次の到達点を「引用付きのテキスト対話」とする。NotebookLM同期と音声が未提供でも、思考支援の基本機能が成立する順序で進める。

Bundleの名称・IDの変更、既存データの一括再分類、外部サービスの会話完全復元は対象に含めない。

## 5. 検証方針

| 対象 | 主な検証 |
|---|---|
| ContextService | 入れ子・動的条件・除外・欠落・競合・範囲固定 |
| 思考状態 | 保存と再読込、本人確認、旧メタデータ保全、同時編集 |
| Conversation | AI停止、引用整合、資料不足、切替競合、中断 |
| Agent | 部分失敗、重複防止、適用差分、基準版不一致 |
| 外部連携 | ID対応、更新判定、再関連付け、切断復帰、権限不足 |
| UI | 4パネル間の操作、狭い表示、Simpleモード、キーボード、停止・エラー表示 |

純粋な状態処理は単体テスト、サービス境界は統合テスト、操作の連続性はブラウザ／Electronの実機確認で検証する。外部APIは検証用資料・接続先で実証し、保存をモックしたテストと区別して記録する。

## 6. 変更の保全と戻し方

各段階を独立した変更単位としてコミットし、成果物と検証結果を記録する。旧コードは比較・互換確認に利用するが、旧ルートをそのまま本番のAI経路へ戻さない。

新規保存項目はスキーマ版を持たせ、移行時に元データを保全する。AIを停止しても、新たに作った手動記録と成果物は読める状態を維持する。外部同期を止める操作が、ローカルや外部の資料削除にならないようにする。
