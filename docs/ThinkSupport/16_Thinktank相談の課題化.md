# Thinktank相談の課題化

## 目的

ThinktankのAIChatで話した内容を、本人が課題として扱うと決めた時点で1件のBundleへ移し、Overviewで管理を始められるようにする。AIの応答だけでは課題を作成しない。

## 操作

Thinktankの上部リストでChatを選択し、「この相談を課題として始める」を押す。Chatタイトルの担当パネル・状態などの識別部分を除いた名称を初期値として表示する。本人が課題名を確認または編集し、「作成してOverviewで開く」を押すと課題Bundleを保存してOverviewのグラフ表示で開く。

## 保存内容

課題Bundleの先頭行には確認済みの課題名を保存する。選択ChatのIDをBundle本文の`*`行へ保存し、ストレージの関連IDにも同じIDを保存する。これにより、Overview・Workout・ReThinkのAIChat一覧は既存ルールに従って、当該Bundleに含まれるChatを候補にできる。質問と回答の保存先は引き続き選択Chatであり、Bundleへ会話本文を複製しない。

課題名の改行は空白に直し、空欄と200文字超を拒否する。存在しないIDと同じIDの重複は保存しない。保存に失敗した場合はメモリ上に未保存のBundleを残さない既存処理を使う。

## 検証

課題Bundleのタイトル、本文の関連ID、保存メタデータの関連ID、上部Chatからの確認操作を単体・UIテストで確認する。AI接続は課題Bundleの作成に不要である。

## 次の段階

直近のChat単独対話でAIが提示した目的・完了条件を確認し、Bundle作成と同時に課題状態として保存する処理を追加した。詳細は[21 相談から目的と完了条件の引継ぎ](21_相談から目的と完了条件の引継ぎ.md)。対話での修正を含む実機検証と、Overviewでサブ課題案を確認して追加する導線が次の段階となる。
