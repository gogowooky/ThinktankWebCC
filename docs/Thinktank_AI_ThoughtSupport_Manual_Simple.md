## 1. このアプリでできること

Thinktank は、あなたの「気になっていること」「予定」「続けている活動」を書きためて、
AI と話しながら整理していくためのアプリです。

- 覚えておきたいことを書いておけば、頭で覚え続けなくてよくなります。
- 前に何を話し、何を決めたかを、必要なときに思い出せます。
- 迷ったときは、選択肢と選ぶ基準を一緒に整理できます。
- 途中でやめても、あとで続きから戻れます。
- やったことと記録を見比べて、次に生かせます。

AI はあなたの代わりに決めることはしません。あなたが自分で選べるように手伝います。

---

## 2. 覚えなくてよいこと

次のことは AI がやります。あなたが暗記する必要はありません。

- 相談を「TODO」「予定」などに分類すること
- どの画面で相談すればよいか
- 決まったことの要約
- 関連する記録どうしのつなぎ合わせ

あなたが決めるのは、**目的・採用する案・お金や約束にかかわること・やめるかどうか**だけです。

---

## 3. 4つの画面の使い分け

画面は左から右へ、視点が変わります。迷ったら「今いる画面」で短く聞いて構いません。

| 画面 | こんなときに使う |
|---|---|
| **Thinktank** | 気になることを話す／昔の記録をさがす |
| **Overview** | ひとつの課題の全体を見渡す |
| **Workout** | ひとつの件をじっくり考えて進める |
| **ReThink** | 結果を確かめて、次にどうするか決める |

考える中心が変わったら、AI が「全体を見ましょう」などと次の画面へ案内します。
画面はあなたが確認してから切り替わります。勝手には動きません。

---

## 4. 基本の流れ

```
気になる  →  相談する  →  進める  →  確かめる
Thinktank    Overview     Workout     ReThink
```

1. **気になる**：Thinktank で「最近これが気になっている」と話します。
2. **相談する**：Overview で、その課題の目的と、いま何が問題かを整理します。
3. **進める**：Workout で、ひとつずつ「次にやること」を決めて実行します。
4. **確かめる**：ReThink で、やった結果と記録を見比べ、完了・継続・保留などを決めます。

必ず全部を順に通す必要はありません。短い用件はその場で終わらせて構いません。

## 5. 場面別の使い方

### 5.1 気になったことを、とりあえず書く

Thinktank で話すだけで大丈夫です。分類はまだしなくて構いません。
AI が「未整理」として預かり、必要になったときに一緒に整理します。

> 「町内会の名簿、そろそろ直さないと」→ ひとまず記録。義務や予定には勝手に変えません。

### 5.2 前の続きから再開する

Thinktank で「この前の会場の話の続き」と言えば、関連する記録をさがして候補を数件出します。
続きを選ぶと、AI が短くふり返ります。

```
前回：会場を A と B に絞りました。
現在：A の空き状況を待っています。
次：案内文の下書きを進められます。
```

### 5.3 迷ったとき（選択肢を比べる）

Workout で「比較」の表（HTML）を開くと、候補を横並びで見られます。

- Workout の設定にある **file-code（Html設定）** アイコン →「新規（file-plus）」で表示資料を作れます。
- 表を見ながら、AI と「近さと費用、どちらを優先するか」を相談します。
- 表の候補をクリックしただけでは、決定にも予約にもなりません。
- 決めたことは Chat 側に記録されます。表を閉じても消えません。

### 5.4 待っているものを確認する

Overview の **「この課題の状況」** に、状態ごとに相談が並びます。

- **待機**：相手の返事や日時を待っている
- **保留**：わざと止めている
- **進行中**：いま進めている

各行から、元の記録を Workout で開けます。「待機」のままでも、見ただけで状態は変わりません。

### 5.5 終わったこと・続くことを振り返る

ReThink で、記録と実際を見比べます。

- 「記録は未完了だが、もう済んでいないか」
- 「返事は届いたか」「日程は変わっていないか」

結果に応じて、完了・継続・待機・保留・中止・再検討を整理します。
毎月の活動など、続くものの定期的な見直しにも使います。

## 6. AI との付き合い方

**してくれること**

- わかりやすい質問に分けて聞く
- 事実／あなたの決定／AI の提案／未確認、を分けて示す
- 過去の決定は記録を見て答える（見つからなければ「わかりません」と言う）
- 同じことを何度聞いても、おだやかに答える
- 節目に「決まったこと・未決定・次の一手」を短くまとめる

**しないこと**

- あなたの重要な決定を代わりに行う
- 年齢だけで説明の仕方を決めつける
- まだ無い機能（自動通知など）を「やっておきました」と言う
- 表や資料の中に書かれた指示に勝手に従う

言ったことが前と変わっても、AI は「意向が変わったのかも」と受け止めます。
「前は A でしたが、B に変更でよいですか」と確認します。

## 7. 画面に出る言葉のミニ辞典

| 言葉 | 意味 |
|---|---|
| Think（シンク） | 1件の記録。メモ・表・チャットなど種類がある |
| Bundle（バンドル） | 関連する Think をまとめたもの（例：「10月の交流会」） |
| Chat | AI との相談。追跡する「管理Chat」と、雑談・下書き用の「自由対話Chat」がある |
| HTML | 比較・予定・手順などを見やすく表示する資料。閲覧用（今は操作はできない） |
| 種類 | TODO（対応する一件）／PROJ（複数をまとめる活動）／ASK（知りたい問い）／EVNT（日時のある予定）／LOOP（繰り返す活動） |
| 状態 | 未着手／進行中／待機／保留／完了／中止 |
| 回覧板 | その課題の「目的・今の状況・次の一手」をまとめたメモ |
| 再開メモ | 中断したとき、どこまで考えたかを残しておくメモ |

種類・状態は AI が付けます。自分で選ぶ必要はありません。

---

## 8. 困ったとき

| こんなとき | どうする |
|---|---|
| どこで相談すればいいかわからない | いまの画面でそのまま聞く。AI が案内する |
| 前の話を思い出せない | Thinktank で「〜の続き」と言う。記録からさがす |
| 決めたくない／まだ待ちたい | 「今は決めない」「情報を待つ」と言ってよい |
| AI の説明が長い／多い | 「もっと短く」「一度にひとつだけ」と伝える |
| 中断したい | 「今日はここまで」と言うと再開メモを残す |
| 決めたはずのことが違って見える | 記録の根拠を一緒に確認する |
