# はじめてのThinktank ― AIと相談する使い方

作成日：2026-09-08  
対象：思考支援機能を組み込んだアプリを初めて使う方。更新したアプリとAI接続の準備が済んでいることを前提とします。

## 最初に覚えることは3つです

1. 気になることを、そのまま話してください。
2. 前の話を忘れても「前回の続きを教えて」と聞けます。
3. 相談の種類や担当の整理はAIに任せられます。

Thinktankは、覚えておく負担を減らし、考えを整理して次の一歩を決めるためのアプリです。何をしたいか、どの案を選ぶかは、ご自身の希望に合わせて決められます。

## 1. 相談を始める

1. Thinktankパネルの「AI相談」を開きます。
2. すでに別の相談が開いていたら、上の相談一覧をクリックし、先頭の「＋ 新規チャット」を選びます。
3. 下の入力欄をクリックし、気になることを書きます。
4. `Enter` キーで送信します。文の途中で改行したいときは `Shift + Enter` です。

たとえば、次のように入力してください。

> 来月、友人と交流会を開きたいのですが、何から始めればよいでしょうか。

まだ何をするか決めていない場合も相談できます。

> 気になっているだけです。今すぐ取り組む予定にはせず、記録しておいてください。

AIの返事を読み、答えられることから返してください。一度にすべてを決める必要はありません。

入力とAIの応答は自動保存されます。「相談を保存しました」と表示されれば保存が済んでいます。エラーが表示された場合は、下の「困ったとき」を参照してください。

## 2. 担当が変わっても、そのまま続ける

相談の途中で「担当をOverviewに引き継ぎました」などと表示されることがあります。

**そのまま、同じ入力欄で相談を続けてください。** 自分でタグを書き換えたり、別のパネルへ移動したりする必要はありません。

4つの担当には、次の得意分野があります。順番に通る必要はありません。

| 担当 | 得意なこと |
|---|---|
| Thinktank | 気になることを受け止め、前の記録を探す |
| Overview | この課題の全体を整理する |
| Workout | 一つずつ具体的に考え、進める |
| ReThink | 結果や今の状況を確かめ、次につなぐ |

## 3. 前回の続きから始める

前の相談が表示されていたら、そのまま次のように聞けます。

> 前回はどこまで決まりましたか。次にすることを一つ教えてください。

「前回・現在・次を確認する」を開くと、記録された要点を読めます。要点がまだ記録されていない場合は、AIに整理を頼んでください。

相談が見つからなければ、ThinktankのAI相談で探します。

> 前に交流会の会場について話しました。その相談を探してください。

「見つかった相談」に候補が表示されたら、続けたい相談のボタンを押します。新たな相談では、上に表示されている相談名を確かめてから話してください。

## 4. 説明を自分に合わせる

入力欄をクリックすると、その下にAIモデル選択と「説明」が表示されます。「説明」で「短く、一つずつ」「標準」「詳しく」を選べます。会話で頼むこともできます。

| こんなとき | 入力する言葉の例 |
|---|---|
| 説明が多くて分かりにくい | 「一つずつ説明してください」 |
| 前の話を思い出せない | 「前回決まったことを、もう一度教えて」 |
| 選択肢を比べたい | 「費用と行きやすさで比べてください」 |
| 今は決められない | 「まだ決めずに、候補として残してください」 |
| AIの記録が違う | 「そこは違います。正しくは……です」 |

同じことを繰り返し聞いても構いません。前と考えが変わったときも、そのまま伝えてください。

## 5. 進んだこと・待っていることを伝える

アプリの外で行ったことは、AIに教えてください。

> 会場に問い合わせました。今は返事を待っています。

> 予約が取れました。残っているのは案内文の作成です。

AIが内容に応じて状態を整理します。状態は、未着手・進行中・待機・保留・完了・中止です。書式を覚える必要はありません。

「この会場に決めた」と相談に記録することと、実際に予約することは別です。予約などを行った後に、その結果を伝えてください。

後で確認したいことは、日付と一緒に伝えます。

> 9月15日になっても返事がなければ、状況を再確認したいです。

再確認する時期はアプリ内に表示されます。現在は、アプリを閉じている間の通知はありません。

## 6. 全体の状況を見たいとき

関連する相談や資料のまとまりを「Bundle」と呼びます。

Overviewで対象のBundleを開き、「Bundle分析」の「この課題の状況」を見ると、目的、進み具合、次の一手などを確認できます。「この相談を続ける」を押すと、その相談を担当AIと続けられます。

ThinktankのThink一覧はすべての記録、OverviewのThink一覧は選んだBundleの記録を表示します。別のBundleを見ても、相談中の課題が自動的に別の課題へ変わることはありません。

## 7. 今日はここまで、というとき

> 今日はここまでにします。決まったことと、次に再開するところを残してください。

AIのまとめを読み、保存完了を確認してから終えます。次回は「前回の続きから」で再開できます。

課題そのものが終わった場合は、何が終わり、何が残っているかを伝えます。完了した相談も記録に残ります。Chat一覧の「状態」フィルターで「完了」「中止」のアイコンをオンにすると読み返せます。

Chat一覧のフィルター欄の下には「種類」「状態」のアイコンが並びます。各アイコンを押すと表示対象を切り替えられます。種類と状態は組み合わせて使えます。アイコンにマウスを重ねると名称を確認できます。各段の右端で全選択・全解除ができます。初期表示では全種類を対象とし、完了・中止は非表示です。

上段が種類、下段が状態です。文字の見出しは表示しません。選択中のChatに該当するアイコン枠内の右下に「・」が付きます。背景の反転はフィルターがオンであることを示します。「フィルター選択」の「種類」「状態」で、各段の表示・非表示を切り替えられます。

## 慣れてきたら：個別の検討と図表

WorkoutでChatファイルを開いた個別の表示領域を「Pane」と呼びます。ここでは資料の説明、文章作成、候補の比較などを自由に相談できます。

結果を課題全体に渡すときは、Pane上部で「成果の反映先」を選び、「結果を相談につなぐ」を押します。検討内容は参照・確認事項として渡されます。採用案を決めたことにはならないので、反映先の相談で意向を伝えてください。

HTMLファイルは、図表や手順を見やすく表示する資料です。開いた資料の文字は「文字サイズ」で調整できます。元の記録が変わったという案内が出たら、AIChatで資料の確認・作り直しを相談してください。

## 困ったとき

| 表示・状況 | 対応 |
|---|---|
| 読み込みエラー | 「読み込みを再試行」が表示されていれば押します |
| 保存エラー | 「保存を再試行」が表示されていれば押します。成功するまでは保存済みと思わず、必要な文章をコピーしておきます |
| 別の場所で更新されたという案内 | 今回の応答をコピーしてから相談を開き直し、最新の記録を確認します |
| AIとの通信が途中で終わった | 表示された案内を確認し、必要ならもう一度話しかけます |
| AIが担当や状態を意図と違う形で変更した | AIに訂正を伝えます。直前の管理変更なら「直前の管理変更を戻す」も使えます |

「説明」の右にある返信アイコン（マウスを重ねると「直前の管理変更を戻す」と表示）は、相談の担当・状態・管理情報を戻す操作です。入力した文章や、作成済みの資料を削除する操作ではありません。
