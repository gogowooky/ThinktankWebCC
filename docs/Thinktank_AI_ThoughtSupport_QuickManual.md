# Thinktank 思考支援・簡易ユーザーマニュアル

作成日：2026-09-08  
本書は「AIChatによる思考支援とUI運用仕様案」どおりの機能が完成した場合を想定したマニュアル案です。現在のアプリで利用できる機能だけを説明したものではありません。

## 1. まずは、気になることを話してください

Thinktankは、気になることや取り組んでいることをAIと相談しながら整理するアプリです。前の相談を思い出す、選択肢を比べる、次にすることを決める、といった「思考支援」を行います。

最初から考えをまとめておく必要はありません。たとえば、次のように話しかけてください。

> 来月、友人との交流会を開きたいのですが、何から始めたらよいでしょうか。

AIが話を聞き、目的、決まっていること、これから考えることを整理します。まだ取り組むか決めていないことも、そのまま記録できます。

分類やタイトルの書式はAIに任せられます。何をしたいか、どの案を選ぶかは、ご自身の意向に合わせて決めてください。

## 2. 4つのパネルの使い分け

| パネル | こんなときに使います | 相談の例 |
|---|---|---|
| Thinktank | 気になることを話す・以前の記録を探す | 「前に話した交流会の相談を探して」 |
| Overview | この課題の全体を見渡す | 「何が決まっていて、何が残っていますか」 |
| Workout | 一つずつ考えて進める | 「会場の候補を比べたい」 |
| ReThink | 状況や結果を確かめ、次につなぐ | 「今回の結果を整理して、次回に活かしたい」 |

4つを順番に使う必要はありません。小さな相談は一つのパネルで進められます。必要に応じて別の視点へ戻ってください。

どこで相談すればよいか迷ったら、現在のパネルで話しかけて構いません。AIが適した担当を案内し、相談の経緯を引き継ぎます。

### 一覧に見える範囲の違い

Thinktankの「Think一覧」には、すべてのThinkファイルが表示されます。過去の記録も含めて広く探す場所です。

Overviewの「Think一覧」には、設定したBundleに含まれるファイルが表示されます。Bundleは、ある課題に関係する相談や資料をまとめたものです。Overviewで「全体を整理して」と頼むと、このBundleの範囲を中心に整理します。

OverviewにBundleが設定されていないときは、先に対象のBundleを選びます。どれを選ぶか分からないときは、Thinktankで相談を探してください。

## 3. 新しい相談を始める

1. ThinktankのAIChatで、気になることを話します。
2. AIと一緒に「どうなればよいか」「今、何を考えたいか」を整理します。
3. 必要な過去のメモや資料を、相談に関連付けます。
4. 全体を整理したいときはOverviewへ、具体的に進めたいときはWorkoutへ移ります。

資料はThink一覧からBundleへドラッグ＆ドロップしてまとめられます。AIに「このメモを交流会の資料に加えて」と頼むこともできます。

大きな取り組みは、必要に応じて小さな課題に分けます。交流会なら「会場を決める」「案内文を作る」などです。元の相談と小さな課題は関連付けられるので、後から行き来できます。

別のことが気になったら、次のように伝えてください。

> それは別の相談として残して、今は交流会の話を続けたいです。

## 4. 前回の続きから再開する

以前の相談を開いて、次のように伝えます。

> 前回の続きからお願いします。どこまで決まりましたか。

AIが「前回の内容」「現在の状況」「次にすること」を短く示します。必要なら、元になった記録も確認できます。

アプリの外で進んだことや、気持ちが変わったことも伝えてください。

> 昨日、会場から返事が来ました。土曜日なら使えます。

> 前は大人数を考えていましたが、今回は少人数にしたいです。

記録と今の状況が違っていても構いません。今の意向や事実に合わせて整理し直します。

途中でやめるときは「今日はここまで。次に再開するところを残して」と伝えれば、決まったこと、未決定のこと、次の行動をまとめて残せます。

## 5. Overviewで、この課題の状況を見る

対象のBundleを設定し、「Bundle分析」の「この課題の状況」を開きます。

ここでは、課題の目的、進み具合、次にすること、返事待ちのことなどを確認します。課題同士のつながりを見たいときは「関係グラフ」に切り替えます。

一覧だけでは分かりにくいときは、AIChatで聞いてください。

> 今、私が決める必要があることを一つだけ教えてください。

> 返事を待っている間に、進められることはありますか。

対象のBundleを切り替えたときは、相談している課題名も確認してください。表示する資料を変えることと、相談の対象を変えることは別です。

## 6. Workoutで、一つずつ進める

Workoutには、用途の異なる2つのチャットの場所があります。

| 場所 | 主な使い方 |
|---|---|
| パネルのAIChat | 課題の進み具合を確認し、個別の検討結果をまとめ、次の行動を相談する |
| Chatファイルを開いたPane（個別の表示領域） | そのチャットで自由に質問し、資料の説明、比較、文章作成などを行う |

たとえば、Paneで「この2つの会場の違いを表にして」と相談し、比較を進めます。採用したい結果がまとまったら、次のように伝えてください。

> この比較結果を、交流会の課題に反映してください。会場はまだ決定していません。

個別のPaneで話した案が、そのまま課題全体の決定になるわけではありません。「候補にしたい」「これに決めた」を言い分けると、記録が明確になります。

また、AIとの相談で「この会場に決めた」と記録しても、実際の予約が済んだことにはなりません。予約などを行った後で、その結果を伝えてください。

### HTMLで図や表を見る

HTMLファイルは、MemoやChatと同じように扱うThinkファイルの一種です。Paneで開くと、図、表、手順などを見やすく表示できます。

新しく作るときは、Workoutの「Graph設定」の下にある「Html設定」（file-codeアイコン）を開きます。「Html」項の「新規」（file-plusアイコン）を押してください。

Paneでは、表示を見る方法と、TextEditorでHTMLの内容を編集する方法を切り替えられます。表示文字の大きさも調整できます。普段の確認では、HTMLを編集する知識は必要ありません。

HTMLは状況を見やすくする資料として使います。課題の状態変更や決定はAIChatで行い、状況が変わった後は表示資料も最新か確認してください。

## 7. ReThinkで確かめる・いったん区切る

一区切りついたときや、しばらく間が空いたときは、ReThinkで振り返ります。

> 交流会の準備について、終わったことと残っていることを確認したいです。

AIと一緒に、実際に終わったこと、まだ必要なこと、変わった事情を確認します。そのうえで、続ける、待つ、休む、完了するなどを決めます。

全体の計画を考え直すならOverviewへ、個別の作業を深めるならWorkoutへ戻れます。毎月の活動などは、今回の結果を記録し、次回の準備につなげます。

同じ話が続いていても、解決したことにはなりません。「何が決まらずに残っているか整理して」と頼んでください。

## 8. 状態と予定の扱い

| 状態 | 意味 |
|---|---|
| 未着手 | 取り組むことは決めたが、まだ始めていない |
| 進行中 | 考えたり、作業したりしている |
| 待機 | 返事や、開始できる条件が整うのを待っている |
| 保留 | 自分の判断で、いったん取り組みを休んでいる |
| 完了 | 目的を満たし、終了した |
| 中止 | 取り組みをやめた |

「まだ取り組むか決めていないアイデア」は、未着手の仕事として増やす必要はありません。「将来の候補として残して」と伝えられます。

日付を伝えるときは、その意味も添えてください。

- 「案内を送る期限は10月5日です」
- 「案内文は10月2日の午前に作りたいです」
- 「会場の返事がなければ、10月3日に再確認したいです」

日付を過ぎただけで完了にはなりません。実際にどうなったかを確認して記録を更新します。再確認日の記録と通知の有無は別なので、通知が必要な場合は利用できる通知機能と設定を確認してください。

繰り返す活動は「毎月の交流会として管理したい」と伝えます。共通の準備手順と、各回の予定・結果を分けて整理できます。

### タイトルの記号は覚えなくても使えます

相談のタイトルには、たとえば `TODO:Workout｜[未着手]会場を予約する` と表示されます。種類、担当パネル、状態、相談名を示しています。

種類は、TODO（個別の課題）、PROJ（複数の課題をまとめる取り組み）、ASK（質問・相談）、EVNT（1回の行事）、LOOP（繰り返す活動）です。分類はAIに任せ、違うと思ったときに伝えてください。

## 9. 困ったときの頼み方

| 困ったこと | そのまま入力できる言葉 |
|---|---|
| 前の話を思い出せない | 「前回決まったことを、短く教えて」 |
| 説明が多くて分からない | 「一つずつ説明してください」 |
| 選べない | 「私が大事にしている条件で、違いを比べて」 |
| AIの記録が違う | 「そこは違います。正しくは……です」 |
| 決定したことにされている | 「それは候補です。まだ決めていません」 |
| 話を中断したい | 「今日はここまで。続きを残して」 |
| 何から始めればよいか分からない | 「今できる小さな一歩を、一つ提案して」 |

同じことを繰り返し聞いても構いません。説明の長さや進める速さも、ご自身に合うように伝えてください。
