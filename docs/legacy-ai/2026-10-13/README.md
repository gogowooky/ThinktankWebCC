# 停止済みAI・SSE実装の保全

2026-10-13のB4整理で、現行入口から実行されない旧AI・SSE実装と専用テストを通常のソース・ビルド・テスト対象から隔離しました。元の状態はコミット `53a1863` と、このディレクトリの原文スナップショットで確認できます。

`manifest.json` に元のパス、保全先、SHA-256、扱いを記録しています。`snapshot/` 以下は元のパスに `.txt` を付けた参照用ファイルで、TypeScript・Vitest・パッケージには含めません。そのまま実行するための別プロジェクトではありません。旧実装を調査する際は、元のコミットと当時の依存関係を参照してください。

- 旧SupportChat、AiChatView、SSEクライアント/ルート、ChatService、Gemini専用ヘルパー、旧モデル許可リスト、旧作用適用処理と専用テストを隔離。
- 現行側が使うモデル選択Propsと停止用ChatApiの型は、独立した型ファイルへ移動。
- `thoughtSupport.ts` は旧メタデータの読込と再確認日の判定を保持。旧会話本文・管理情報・未反映処理の保存データは変更していません。
- `aiModels.ts` は現行のパネルモデル選択・設定移行・表示名・保存形式を保持し、旧UIだけが使った関数を整理。
- 現行の停止用 `/api/chat` と停止用ChatApi shim、現在のAIProvider・会話・Agent・FileSearchは維持。
- 旧経路専用の `@anthropic-ai/sdk`、`@google/generative-ai`、`openai` を直接依存から除去。保持するパッケージの版変更はありません。

将来のAI接続は現行サービス境界を利用してください。スナップショットを本番入口へ戻す再有効化スイッチは設けていません。実Vault・BigQuery・Drive上のデータやテーブルの削除・移行は行っていません。
