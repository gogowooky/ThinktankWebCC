# 2026/07/20 [整備完了] 本アプリのTODO支援機能の概要説明 =======================================================================================
指示> 本sectionの情報を元に、[要対応]項目の記載整備して下さい。

・本機能は、複数のAIChat用パネル（Thinktank／Overview／WorkoutSetting／Workout各Pane／ReThink）を連携させ、ユーザーのTODO処理をAIが段階的に伴走支援する仕組みである。
・中核となるのは「TODO回覧板」と「Bundleファイル」であり、この2つは別々のファイルとして対になって存在する。
  - TODO回覧板：Thinkファイルの一種。作成時にユーザーが記載する「主課題・したいこと」と、以降AIが更新する「課題対応状況の概要」「現在の課題」「担当AI名」を持つ、進行管理専用のThinkファイル。
  　markdownフォーマットで記載され、
  　「主課題・したいこと」「課題対応状況の概要」「現在の課題」「担当AI名」はすべて、同Header名のLevel1のSecion内に平文で記載される。
  - Bundleファイル：Thinkファイル一覧を記載したthinkファイル。TODOは記載されたファイルのみを用いて処理される。
  - ThinktankパネルのAIChatは、ユーザー対話によって実施したいTODO処理の情報を収集し、TODO回覧板とTODO回覧板ファイルだけを含むBundleファイルの両方を新規作成する。
・担当AIによるハンドオフフロー：
  - 回覧板には現在の担当AI名が記載されており、担当となったAIがユーザーに問い合わせて課題を解決する。
  - ユーザーへの問い合わせ担当となったAIはAIChatアイコンの色を変えてアラートを示す。
  - 課題解決後、担当AIは回覧板を次の課題内容に書き換え、次の担当AIを指定する。引き渡し時はUI側で次パネルへの自動通知・自動遷移も行う。
  - ただし同時に複数のTODO回覧板ファイルが存在しうるため、Overview／WorkoutSetting／ReThinkの各パネルには、対象となる回覧板ファイルの一覧を表示するUIを設ける（自動検知だけに頼らず、どの回覧板を処理中か判別・選択できるようにするため）。
・Workout各PaneのAIChatは、この担当AIループ（回覧板を介した課題対応）には含まれない。あくまでmemoファイル内での調査・まとめ用のAI Chatであり、TODO処理支援のハンドオフ対象外とする。
・OverviewPanelに対象Bundleファイルが設定されている場合、Overview／WorkoutSetting／Workout各Pane／ReThinkの各AIChatでの対話保存は、すべてそのBundleファイルに追記される。

# 2026/07/20 [整備完了] 追加実装すべき機能 ====================================================================================================

・TODO回覧板テンプレート：Thinkファイルの新規タイプとして追加。markdown形式で「主課題・したいこと」「課題対応状況の概要」「現在の課題」「担当AI名」の4つのLevel1 Sectionを持つテンプレートを新設する。
・回覧板一覧Bundleファイル：回覧板ファイルのみを列挙する専用フォーマットのThinkファイル（Bundleファイル）を追加する。TODO処理はこの一覧に記載された回覧板ファイルのみを対象とする。
・Thinktankパネルの新規作成フロー：ユーザーとの対話から上記2ファイル（TODO回覧板＋回覧板一覧Bundleファイル）を新規作成するAIChatフローを追加実装する。
・担当AI自動検知ロジック：各パネル起動時／Bundle選択時に、対象Bundleファイル配下の回覧板ファイルを走査し、「担当AI名」欄が自パネルと一致するか判定する処理を追加する。
・回覧板一覧表示UI：Overview／WorkoutSetting／ReThinkの各パネルに、対象Bundleファイルに含まれる回覧板ファイルの一覧（担当AI・現在の課題を表示）を表示するコンポーネントを追加する。
・担当AIアラート表示：自分が担当となったAIChatパネルのアイコンの色を変更し、ユーザーに対応が必要であることを示すUIを追加する。
・自動通知・自動遷移：担当AIが次の担当AIに引き渡す際、対応するパネルへユーザーを自動的に遷移させる、またはバッジ通知を出す機能を追加する。
・Bundle連動保存の拡張：OverviewPanelに対象Bundleファイルが設定されている場合、Overview／WorkoutSetting／Workout各Pane／ReThinkの各AIChatの会話がそのBundleファイルに追記される保存ロジックを追加する。

# 2026/07/20 [整備完了] 各パネルのAIChatへの指示プロンプト =====================================================================================
## Thinktankパネル

あなたはThinktankパネルのAIアシスタントです。ユーザーが新しく着手したいTODOについて対話し、「主課題（何を解決したいか）」「したいこと（具体的に実施したい内容）」を明確化してください。
明確化できたら、TODO回覧板ファイル（Thinkファイル・markdown形式。Level1セクション「主課題・したいこと」「課題対応状況の概要」「現在の課題」「担当AI名」を持つ）を新規作成してください。あわせて、この回覧板ファイルのみを列挙する回覧板一覧Bundleファイルを作成し、初期の担当AIを回覧板に記載してください。

## Overviewパネル

あなたはOverviewパネルのAIアシスタントです。表示中のBundleファイルに含まれるTODO回覧板ファイルの一覧をユーザーに提示してください。
担当AI名が「Overview」となっている回覧板がある場合は、AIChatアイコンの色を変えてアラートを示し、当該回覧板の「現在の課題」をユーザーに伝えて対話により解決を図ってください。
課題が解決したら、回覧板の「課題対応状況の概要」「現在の課題」を更新し、次の担当AIを指定したうえで、該当パネルへの自動通知・自動遷移を行ってください。
