# 思考支援のための推奨ショートカット

作成日：2026-09-08  
位置づけ：設定・実装の提案書。今回、キー設定やアプリのコードは変更していない。

## 1. 方針

初心者が覚えるキーは、最初は送信と改行だけにする。パネル移動・タグ変更をキー操作の必須手順にしない。よく使う目的にキーを割り当て、同じ操作を文字付きボタンでも提供する。

## 2. 現在使える基本操作

| キー | 場所 | 操作・注意 |
|---|---|---|
| Enter | AIChatの入力欄 | 送信。現在は入力欄側の処理で実行する |
| Shift + Enter | AIChatの入力欄 | 改行 |
| Tab / Shift + Tab | 標準の入力欄・ボタン等 | 次／前の操作部品へ移動。実際の移動順は画面配置による |
| Enter / Space | フォーカスした標準ボタン | ボタンを押す。入力欄での意味とは異なる |

送信キーを変更するときは、ショートカット表だけではなく、AIChat入力欄のキー処理も変更する必要がある。

## 3. 初心者向けに追加したいキー

以下は未実装の割り当て案。既定ファイルに同じキーが見つからない場合でも、ユーザー設定・ブラウザ・OS・支援ソフトとの競合確認は必要。

| 優先 | 推奨キー | 操作 | 実装条件 |
|---|---|---|---|
| 高 | Alt + J | 現在の相談の入力欄へ戻る | 専用アクション追加。パネル担当は変えず、入力途中の文を保持する |
| 高 | Alt + R | 「前回・現在・次」の表示を開く／閉じる | 専用アクション追加。保存済み要約を表示するだけで、AIへ自動送信しない |
| 中 | Alt + Q | 現在のパネルの相談一覧へ移動 | 専用アクション追加。入力中・保存中の切り替えを考慮する |
| 中 | Alt + Shift + N | 新しい相談を始める | 専用アクション追加。未送信文があれば保持してから開始する |

導入時はAlt + J、Alt + Rの2つを先に用意する。利用者が必要としてから、残りを追加する。

アクションIDを新設する場合の命名案：`ThoughtSupport.Input.Focus`、`ThoughtSupport.Resume.Toggle`、`ThoughtSupport.List.Focus`、`ThoughtSupport.New`。これらは提案名であり、現時点で設定表に記載しても動作しない。

## 4. 送信方法の推奨

現行はEnterで送信する。文章を複数行で書く方や、日本語変換の確定と送信を分けたい方には、次の選択肢を設定として追加する。

| 設定案 | Enter | Ctrl + Enter | 画面上の操作 |
|---|---|---|---|
| Enterで送信 | 送信 | 任意の補助送信 | 「送信」ボタン |
| Enterで改行 | 改行 | 送信 | 「送信」ボタン |

Ctrl + Enterは、現行のEnter判定に入る場合があるが、独立した送信モードとして実装された設定ではない。表の切り替え機能は今後の実装が必要。

どちらの設定でも、日本語変換中のEnterで送信しない処理を優先する。現行の `AiChatView` のEnter判定には変換中の状態を確認する分岐がないため、IMEでの実動作確認と対策が必要。キー表への追加だけでは解消しない。

## 5. 既存アクションを使う設定例

次はThinktank／OverviewのAI相談一覧で使う、設定担当者向けの候補。アクション自体は既存実装にある。現在の個人設定に重複がないことを確認して追加する。

```text
> focus,exmode,key,action,description
Thinktank.Chat,,Alt+ArrowUp,FocusedPanel.AIChat.CursorPos:PrevLine,相談一覧の前の行へ
Thinktank.Chat,,Alt+ArrowDown,FocusedPanel.AIChat.CursorPos:NextLine,相談一覧の次の行へ
Thinktank.Chat,,Alt+Enter,FocusedPanel.AIChat.Cursor:Action,選択した相談の入力欄へ
Overview.Chat,,Alt+ArrowUp,FocusedPanel.AIChat.CursorPos:PrevLine,相談一覧の前の行へ
Overview.Chat,,Alt+ArrowDown,FocusedPanel.AIChat.CursorPos:NextLine,相談一覧の次の行へ
Overview.Chat,,Alt+Enter,FocusedPanel.AIChat.Cursor:Action,選択した相談の入力欄へ
```

この例は現在の4パネル共通設定ではない。既存の `FocusedPanel.AIChat` アクションは、対象DOMを探す処理がThinktank／Overview向けになっている。Workout／ReThinkにも適用するには、その処理の拡張が必要。

また、一覧のカーソル移動で対象Chatが読み込まれる。入力欄で文章を書いているときに誤って相談を切り替えないよう、導入時にフォーカス条件と未送信文の扱いを確認する。初心者の標準設定へ無条件に追加するものではない。

## 6. 設定の保存先と確認方法

現行コードでは起動時に `docs/DefaultShortcut.md` を読み込む。`__tt_shortcuts__` の保存を受けて実行中の設定を読み直す処理もあるが、それだけで次回起動後も同じ設定になるとは扱わない。継続利用する設定は起動時の読み込み経路まで確認する。

設定担当者の確認手順：

1. 現在の設定を保存し、同じキー・フォーカス・モードの割り当てを確認する。
2. 対象アクションが実装済みか確認する。
3. AIChatの入力中、一覧上、個別Pane上で、それぞれ意図した対象だけが動くか確認する。
4. 日本語変換の確定、改行、送信を確認する。
5. アプリを再起動して設定が維持されるか確認する。

パネルごとのモード操作に使う既存のExModeは、慣れた利用者向けに残す。初心者向けの必修操作にはしない。

## 7. 割り当てを急がない操作

- 完了・中止・担当変更：対話を基本とし、誤操作しやすい単独キーへ割り当てない。
- 管理変更の取り消し：文字編集のCtrl + Zとは別の操作なので、同じキーにしない。
- 保存の再試行：通常の自動保存と区別し、エラーが出た場所のボタンを基本とする。
- Pane成果の反映：まず反映先を明確にする。宛先なしで実行できるキーにはしない。
