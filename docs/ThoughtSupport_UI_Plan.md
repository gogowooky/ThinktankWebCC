# 思考支援UI追加計画

## 今回の範囲

1. Overviewの既存「Bundle分析」に「この課題の状況」を追加する。対象Bundle、管理Chatの状態別一覧、状態未設定、関連資料を表示し、元ThinkをWorkoutで開けるようにする。既存の関係グラフも切り替えて利用可能にする。
2. Memo・Chat・Tableと同じContentTypeとして `html` を追加する。一覧、種別フィルター、サーバー保存検証、作成、Bundle登録、Workout表示を接続する。
3. HTML Thinkは他種別と同じ「1行目がタイトル、2行目以降が本文」の形式とする。本文をHTMLとして閲覧し、テキストエディタでソース編集する。
4. HTML閲覧は隔離したiframe内で実行する。初期実装はスクリプト、フォーム送信、外部通信・画面遷移を許可しない閲覧専用。文字サイズを変更できる。

## 表示と記録

- 管理Chatのタイトル `種類:担当｜[状態]タイトル` を解析する。TODO/PROJ/ASK/EVNT/LOOPを認識する。
- 状態のない既存TODOは「状態未設定」。未着手や完了を推測しない。
- 状況表示は記録されたタイトルと状態から作成する。AIによる状況判断や架空の要約・進捗率は表示しない。
- Bundleを切り替えた際に前の非同期取得結果を表示しない。失敗時は再試行できる。
- 今回は運用AIのプロンプト変更、自動引き継ぎ、通知、HTML内からの状態更新は含めない。

## 検証

- タイトル解析、HTMLの隔離・サニタイズ、html保存種別の検証をテストする。
- フロント・サーバーの型検査、既存テスト、ビルドを実行する。
- 開発用の隔離された表示確認で、空Bundle・状態別表示・HTML表示とソースを確認する。実Vaultへのテストデータ追加は行わない。

## 使い方

- Overviewの「Bundle分析」から「この課題の状況」「関係グラフ」を切り替える。状況表示はBundle内の管理Chatを担当に関係なく状態別に表示する。各行を押すとWorkoutで元ファイルが開く。
- WorkoutのGraph設定の下に、file-codeアイコンの「Html設定」を配置。「Html」項の「新規」（file-plus）から比較表のひな形を持つHTML Thinkを作成し、PaneのHTML表示で開く。
- TextEditor設定の読み込みボタンから `.html` / `.htm` を取り込める。外部HTMLのファイル名をThinkのタイトルとし、ファイル内容を本文として保存する。
- HTML ThinkのPane上部から「HTML表示」「HTMLソース編集」を切り替える。保存ボタンからHTML本文を `.html` として書き出せる。
- 一覧のHTMLフィルターを使用でき、既存のThinkと同じ操作でBundleに追加できる。
- 閲覧用HTML内のリンク・フォーム・スクリプトは動作しない。外部画像等は読み込まない。インラインCSSとデータ画像は利用可能。

## 実装・確認結果

- 上記の状況表示、HTML種別、作成・読み込み・書き出し、ソース編集とプレビューを実装。
- 既存テストを含む142件と、追加のHTML保存・再読み込みテスト1件に合格。
- フロント・サーバーの型検査、追加コンポーネントのESLint、ビルドを確認。
- 実Vaultを使わないブラウザ確認で、状態別一覧、元ThinkのIDを渡す操作、空の一覧への切り替え、HTML描画と文字サイズ変更を確認。
- 外部ストレージへの実接続による書き込み、Electronインストーラー作成・再インストールは今回の確認範囲外。
